Site font: Archia (self-hosted .woff2, five weights). Light/regular for paragraphs, semibold+ for subheads and pull quotes.
Note on this specimen: Nudica Mono and Archia are licensed, self-hosted font files and can't be embedded in a shareable page like this one. The specimens above are set in Space Mono and Manrope (both free on Google Fonts) as close-fit stand-ins so this guide stays usable anywhere — production graphics should still pull the real files from the WordPress media library (/wp-content/uploads/2026/08/sd-*.woff2). A third face, Bariol, is also loaded on the site in regular/bold for occasional UI accents.

Logo Marks

Two active identities: an illustrated mountain mark for cover art, a typographic wordmark for the web.

SideDish actually runs two marks side by side, and they don't share a palette — worth knowing before you drop either one into a template. The mountain badge below is what shows up as podcast cover art and profile pictures; the typographic lockup is what's live on the website's own header and nav.

04

Voice & Tone

Lifted straight from the site's own copy — the show already knows how it sounds.

Everything you want to know and very little you need to know.— homepage tagline
Local interviews, idle gossip, food chatter, and "news."— site meta description
  • Self-aware, not self-serious Titles like "chief gossip officer" and the scare-quoted "news" desk do the work — let the bit land instead of explaining it.
  • Local-insider, not tourist-facing Write like a regular at the counter, not a visitor's guide. Namedrop Longmont specifics freely.
  • Short lists over long sentences The site's own copy favors quick, comma-strung lists ("interviews, gossip, chatter, news") — that rhythm travels well to captions.
